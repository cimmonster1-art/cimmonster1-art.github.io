01 — Website / HTML, CSS, JavaScript

Daylight Café

02 — Browser tool / JavaScript, JSON

ScopeKit

A website brief is rarely enough to start building. ScopeKit turns it into a first draft of deliverables, acceptance checks and questions you can edit before work starts.

How it works

Keyword rules suggest a starting scope. Users edit the result, export Markdown, and save or restore JSON. It runs in the browser without an account or model calls.

Codex-assisted prototype. Suggestions need human review; it does not fully interpret a client's intent.
