# Charli Myers | Software and data portfolio

[Open the portfolio](https://cimmonster1-art.github.io/) · [Project directory](PROJECTS.md) · [Public CV](charli-myers-public-cv.pdf)

A focused introduction to personal software, scientific visualization, browser-tool and data projects. Includes verified Devpost participation and explicit status for unfinished Kaggle work.

## Run locally

```sh
python -m http.server 8765
```

Open http://localhost:8765. No framework, package installation, service credentials or build step is required. GitHub Pages serves the repository root on `main`.

## Contents

- `index.html`: responsive, accessible static portfolio with category filters and expandable project notes.
- `PROJECTS.md`: complete repository mapping and review decisions.
- `charli-myers-public-cv.pdf`: public CV without private contact details.

The full application CV with private contact details is maintained separately and is not published here. Illustrations are original conceptual diagrams, not screenshots. Project source keeps its original license and visibility. No private source or credentials are bundled.
